# Независимая пересборка SEO-файла JEWEL

Отдельный локальный инструмент для редакторской проверки 58 карточек JEWEL. Он не подключён к кнопке подготовки файла и сам не меняет версии задач, карточки WB или настройки модели. Готовый файл можно добавить следующей версией через административный `import_review`; [контракт импорта](automatic-seo-workflow.md). Старый генератор этим изменением не исправлен. Фактический статус размещения — в WORK.md.

## Источники и результат

Вход — явно переданный gzip JSON со своими исходными карточками, назначенными конкурентами, строками MPStats и справочниками характеристик. Для сборки 03.11.2026 сохранён снимок собственных данных от 29.10.2026 и период MPStats 29.09–28.10.2026. Это не обновление витрины.

Пакет `var/research/2026-11-03-seo-contract-review/frozen-source-complete.json.gz` содержит 27 784 исходные строки MPStats и 293 фразы из текстов конкурентов. Последние повторно сверены с настоящими заголовками/описаниями; частотность им не присваивается. Старые сгенерированные предложения и ready-статусы не используются. Собственные текущие описания сохраняются и расширяются; конкретные ошибки собственных исходников исправляются с видимым указанием расхождения.

Результат — восемь листов: итог, семантика, заголовки, характеристики, описания, конкуренты, противоречия, изменения. Все исходные характеристики открыты. Неподтверждённое значение конкурента остаётся отдельным кандидатом, а не внесённой характеристикой. Подробная своя комплектация сохраняется при дополнении.

## Запуск

Нужны Python и зависимости проекта из `requirements.txt`.

```bash
python tools/rebuild_seo_review.py \
  --sources var/research/2026-11-03-seo-contract-review/frozen-source-complete.json.gz \
  --questions var/research/2026-11-03-seo-contract-review/revalidated-source-questions.json \
  --output var/research/2026-11-03-seo-contract-review/JEWEL_SEO_rebuilt_58_2026-11-03.xlsx
```

Сам инструмент не вызывает модель, не читает приложение/БД и не публикует данные. Он сохраняет проверенные JSON по SKU и отчёт `final-verification.json` рядом с файлом. Входные файлы содержат данные конкретного кабинета; их не переносят в другой кабинет.

## Проверки и ограничения

- Заголовок до 59 знаков. Собственное название серии сохраняется. Материал и подробный состав могут находиться в описании и характеристиках.
- Новое описание не короче исходного и до 5000 знаков. Известные спорные размеры нейтрализуются, обе собственные цитаты остаются на листе противоречий.
- Релевантность оценивают правила вида товара, состава, бренда, цвета, материала, количества и подтверждённых свойств. Неясное намерение/свойство получает отдельное решение с основанием. Это не независимая экспертная оценка каждой строки.
- Для каждой строки, признанной релевантной, проверяется размещение. Точное вхождение отдельно от словоформ/адаптации. Составной запрос может иметь несколько настоящих цитат, разделённых `[…]`; совпадение компонентов не объявляется доказательством смысловой связи. Отрицание и направление подарка не должны переноситься на другой предмет/получателя.
- Число ножей/чашек сверяется с компонентами, а общее число предметов — с комплектом. Размер насадки не доказывает объём ведра.
- Новое подтверждённое значение характеристики проверяется по собственным данным. Страна, ударопрочность, СВЧ и уход не выводятся из карточки конкурента.
- При отсутствии размещения или нарушении проверки финальный экспорт не выполняется. Готовый XLSX перечитывается: состав/порядок, значения запросов/count/источников и описаний, открытые строки/столбцы, отсутствие формул.

`quality.audited=true` относится к автоматическим проверкам источников и размещения. `requiresSpecialistReview=true` остаётся обязательным: правила и модельная редакторская сверка не заменяют содержательную приёмку Настей. Особенно важно проверить составные адаптации и отложенные решения. Этот локальный компилятор рассчитан на товарные группы текущей пачки, включая смешанный набор ножей и принадлежностей; готовность произвольных 110 карточек не подтверждена.

Модельная проверка 58 текстов выполнена отдельно через существующий GigaChat-2-Max. Её ответы сохранены для разбора: часть цитат выдумана, часть советов противоречит лимиту заголовка или предлагает вернуть спорные цифры. Такие советы не применяются автоматически.

Целевые проверки: `python -m unittest tests.test_seo_clean_rebuild`.
