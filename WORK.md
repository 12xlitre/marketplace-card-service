## Разбор повторного сбоя

Причина `seo_card_failed`: слишком большой ответ GigaChat содержал повреждённый JSON; 60-секундный лимит и потеря диагностики скрывали реальную ошибку. Последующие проверки выявили ложные заявления о вхождениях, перенос чужих фактов и переспам из-за хештегов/всего списка запросов во входе писателя.

Исправлено: безопасная диагностика; короткие native function_call для анализа и плана; релевантность v3 порциями по 32 запроса только по собственным фактам без хештегов; отдельное написание простым текстом из своих данных, структуры и выбранных фраз. Полный чужой текст писателю не передаётся. Проверяются цитаты, ID/словари, реальные вхождения; поля вне замечания сохраняются до проверки. Markdown удаляется; потерянное числовое условие восстанавливается полным исходным предложением с объяснением. Служебный recheck использует сохранённые ответы без модели/MPStats; доступен также заблокированному файлу на проверке, сохраняет область замечания. При недостатке снимка новые платные вызовы запрещены.

Живая версия 14 собрана для двух SKU, проверка обнаружила потерю «4 см». ## Что изменено по правилу Насти

Ранее описания дополнялись вручную выбранными синонимами в коротком абзаце; системного правила количества не было. Теперь сначала разобраны три фактических описания конкурентов и составлен явный перечень употреблённых формулировок. Для комплектов из 9 форм выбраны 8/9, для смесителей из 10 — 7/7, для душевой системы из 11 — 7. Объединения вариантов и исключения объяснены. Это счётчик разных формулировок перечня с явно показанными вложенными фразами, а не независимых смысловых групп или всех возможных n-грамм.

На листе «Конкуренты» — полные исходные тексты, версии и структура. В «Семантике» — решения и реальные фрагменты/вхождения источника и нашего текста. Для новых текстовых формулировок без MPStats-наблюдения частотность/позиция пустые. Прежней декларации «по смыслу в описании» нет. Отдельные свойства/рекламные обещания источника исключены, их не считают дополнительными ключами.

Проведена редактура тем же помощником и проверка сохранности выбранных фраз/чисел; внешний хьюманизатор не подключён. Пилот фиксирует решения на пяти карточках; реализация кнопки на его основе описана выше.
